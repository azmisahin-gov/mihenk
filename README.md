# MİHENK — Application Repository

> **Status:** Reserved for future implementation; no application code yet.

This repository is reserved for the new MİHENK application: source code, tests, CI, build and release assets only.

Product discovery, workflow research, requirements, decisions and architecture notes live in [mihenk-arge](https://github.com/azmisahin-gov/mihenk-arge).

## Development gate

Implementation begins only after the project owner approves the product scope, first release, architecture, data classification, security model, repository visibility and license.

MİHENK is a clean-room project. Do not copy or port code, architecture, schemas, dependencies, components or packages from earlier Forensic Transcriber projects.

## Repository safety rules

Never commit real case materials, audio/video, reports, court documents, UYAP screenshots, file numbers, party/expert identities, personal or sensitive data, production logs, passwords, tokens, signing certificates or private keys.

This repository is currently public. Treat every pushed file and commit as publicly visible. Public visibility is not itself an open-source license. Before adding implementation code, the project owner must consciously decide whether the source should remain public or the repository should become private, and choose a license policy.

No credentials or case data belong in source code, tests, fixtures, sample assets, logs or GitHub issues.
